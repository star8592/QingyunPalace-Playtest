# 青云宫 R89 · 自然山岳三维实时试玩

独立研发预览地址：https://star8592.github.io/QingyunPalace-Playtest/

场景使用真实Three.js、GLB、三座完整悬浮峰。鼠标左键旋转，滚轮缩放，右键平移。选④⑤⑥看整座山，点「R89 整体岩峰」实时切换旧倒锥山体和新的连续崖壁山体。R88宫殿台基仍可单独切换。

R89是受武当山山脊、断崖和道教宫观位置，以及三清山花岗岩峰墙、节理和深谷启发的岩体改造。三座山保留R58真实坐标及原峰顶位置，把下部倒锥轮廓改为更宽厚的断崖和侧岩壁；清除过时的导航引导线、假接地白色廊桥、部分失去根部的旧林木及零散锥石。全部变换可逆，R88旧入口依然保留。

这只是地质艺术重构原型，尚非真实DEM、纹理精修、完全可通行的NavMesh，也没有建成陆地到悬浮峰的路。不能把间隙上的直线当成登山道。
